Comment le site est fait

Les canaux branchés, les scripts, les données, les règles et les limites rencontrées.

Les canaux

CanalCe qu'il apporteÉtat
API France Travail « Marché du travail »Offres, embauches, tension, salaires en poste, par trimestre ou par annéeBranché
API France Travail « ROME 4.0 » (métiers, fiches métiers)Appellations et compétences officielles de M1703Branché
API France Travail « Offres d'emploi »Annonces détaillées (salaires affichés, compétences)Absente de mon compte développeur
API France Travail « La Bonne Boite »Entreprises à fort potentiel d'embaucheActivée mais erreur 403

Aucun scraping de LinkedIn, de l'APEC ou d'Indeed : leurs conditions d'utilisation l'interdisent.

Les scripts et les données

  • scripts/test_connexion.ps1 : teste la connexion à l'API (n'affiche jamais les identifiants).
  • scripts/marche_du_travail.ps1 : offres par trimestre → data/marche_travail_AAAA-MM-JJ.csv.
  • scripts/indicateurs_marche.ps1 : tension, embauches, salaires → data/indicateurs_AAAA-MM-JJ.csv.
  • scripts/rome.ps1 : appellations et compétences → data/rome_*.csv.
  • scripts/build_site.ps1 : prépare donnees.js, lu par les pages.
  • data/raw/ : les réponses brutes de l'API, conservées pour vérifier chaque chiffre.

Chaque fichier de données porte la date de son extraction dans son nom. Relancer un script crée un nouveau fichier daté : plusieurs extractions permettent de voir le marché bouger.

Les règles

  • Chaque chiffre est présenté avec sa requête, sa date, son canal et ses limites.
  • Les identifiants de l'API sont dans un fichier .env exclu du dépôt et du zip.
  • RGPD : aucun contact nominatif n'est collecté dans ce site. Un contact n'est conservé que pour une finalité claire (candidature), en lien avec sa fonction, avec possibilité de s'opposer.

Les limites rencontrées

  • L'API « Offres d'emploi » n'apparaît pas dans le catalogue de mon compte : je n'ai pas d'annonces détaillées.
  • « La Bonne Boite » répond 403 malgré une activation et un jeton accepté.
  • Les statistiques sont arrondies et agrégées : elles décrivent le marché, pas des offres individuelles.

Le dépôt est aussi en ligne : github.com/jasrosejsw-lab/veille-chef-de-produit.
